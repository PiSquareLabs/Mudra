ISL · INCLUDE · TFLite

ISL sign classifier

Train a small Indian Sign Language word classifier from MediaPipe landmarks, then ship it to a Flutter Android app as a single TFLite file. All preprocessing lives inside the model, so the app only sends raw landmarks.

Quick start App input format

Pipeline

1 · Extractextract_landmarks.py — videos to (frames, 61, 2) arrays with MediaPipe Tasks (pose + hands).
2 · Traintrain.py — signer-split training of a ~1 M parameter causal depthwise-conv network.
3 · Exportexport_tflite.py — float16 and INT8 files, verified against Keras.
4 · Trylive_demo.py — webcam test on your laptop using the .tflite file.

Quick start

pip install -r requirements.txt
pytest

python extract_landmarks.py /path/to/INCLUDE --out out --signer-regex "(?i)(?:user|signer)[_ ]?(\d+)"
python train.py --data out
python export_tflite.py --model out/model.keras
python live_demo.py --model out/model_fp16.tflite --labels out/labels.json

Full instructions, including how to download INCLUDE, are in the project README.

Android app input

One TFLite input tensor, float32, shape [1, 32, 61, 2]: 32 frames, 61 points, x/y in 0–1 image coordinates. Use NaN for missing points. Output is a softmax over the labels in labels.json.

RowsContent
0–18Pose indices 0–16, 23, 24
19–39Person's LEFT hand (21 points)
40–60Person's RIGHT hand (21 points)
